How to Connect This Bot to Your Website

Your bot and website share the same live database and product catalog

This FastAPI engine provides full REST APIs with CORS enabled. Any frontend website (React, Next.js, Vue, WordPress, Shopify, or plain HTML) can call these endpoints to display live products, accept reservations, and allow customers to track repair tickets online.

GET /api/products

Fetch catalog with search, brand filters, and pagination.

GET /api/categories

Fetch categories (Samsung, Motorola, Vivo, Appliances).

POST /api/reservations

Allow website visitors to reserve any product for 24 hours.

GET /api/repairs/{ticket_number}

Embed a repair tracker widget right on your website.

Example: Fetch Products on Your Website (JavaScript) 
// 1. Fetch live products from this bot's backend:
const res = await fetch("http://localhost:8000/api/products?brand=Samsung");
const data = await res.json();

// 2. Render items and WhatsApp order button:
data.items.forEach(product => {
  console.log(product.name, product.price, product.image_url);
  // Each product includes a pre-made WhatsApp Click-to-Chat link:
  // <a href="${product.whatsapp_order_link}" target="_blank">Order on WhatsApp</a>
});
